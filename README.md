# FORENSIX

Virtual Crime Scene Investigation & Forensic Training Platform.

## Prototype 0.1

This is the initial frontend shell. The next milestones are:

1. Case selection
2. Interactive Case 001 scene
3. Evidence discovery and documentation
4. Collection and packaging
5. Chain of custody
6. Sketch tool
7. Timeline and hypothesis
8. Final report
9. AI evaluation
10. Admin case creator

## Run

Install Node.js, open this folder in a terminal, then run:

npm install
npm run dev

Open the local URL shown by Vite.
